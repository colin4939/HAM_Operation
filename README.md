# Amateur Radio Operating Reference

A compact, printable reference for amateur radio operators. It brings together phonetics, signal reports, UTC conversion, Q signals, operating procedure, and U.S. state and Canadian province and territory abbreviations.

## Contents

- **Phonetics and RST:** alphabet pronunciations and signal-report scales
- **UTC:** local-to-UTC offsets for selected North American time zones
- **Q signals:** commonly used codes first, followed by additional codes
- **Abbreviations:** U.S. states and Canadian provinces and territories

Q-code usage can vary by operating mode and context. The list is a practical reference, not a complete list of all Q signals.

## Formats

The reference is available as editable Word documents and LaTeX source. To build a PDF from a `.tex` file, use a LaTeX distribution such as TeX Live or MiKTeX:

```sh
xelatex ARRL_Operating_Reference.tex
```

Alternatively, use `pdflatex` on the same file. The source uses common LaTeX packages, including `tabularx`, `xcolor`, and `hyperref`.
